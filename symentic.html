Features of HTML 5

HTML5 is the latest version of HTML, which is the standard markup language for creating web pages. It includes new features and improvements over previous versions, such as:

  • New elements, attributes, and behaviors
  • Support for multimedia (audio and video)
  • Improved support for graphics and visual effects (Canvas and SVG)
  • Enhanced form controls (e.g., date pickers, sliders)
  • Support for offline storage and caching
  • Improved semantics and accessibility

Usage Symentic tags

Semantic HTML tags are HTML tags that convey meaning about the content they contain. They help search engines and browsers understand the structure and purpose of a web page. Examples of semantic HTML tags include:

  • <header> - Represents the header of a document or section
  • <nav> - Represents a navigation menu
  • <article> - Represents a self-contained piece of content
  • <section> - Represents a thematic grouping of content
  • <footer> - Represents the footer of a document or section

Using semantic HTML tags can improve the accessibility and search engine optimization (SEO) of a web page, as they provide additional context and meaning to the content.

For example, using the <header> tag to wrap the header of a web page can help search engines understand that this section contains important information about the page, such as the title and navigation links.

Similarly, using the <article> tag to wrap a blog post can help search engines understand that this section contains a self-contained piece of content that can be indexed and shared.

Overall, using semantic HTML tags can help improve the structure and meaning of a web page, making it easier for both users and search engines to understand.

Example of Semantic HTML

Here is an example of a simple web page using semantic HTML tags: <!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
</head>
<body>
    <header>
        <h1>Welcome to My Web Page</h1>
         <nav>
         <a href="#about">About</a>
     </nav>
</header>
<main>
    <section id="about">
        <h2>About Me</h2>
         <p>I am a web developer with a passion for creating beautiful and functional websites.</p>
     </section>
<section id="projects">
        <h2>My Projects</h2>
         <ul>
         <li>Project 1</li>
     </ul>
    </section>
</main>
